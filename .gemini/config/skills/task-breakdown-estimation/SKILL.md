# Task Breakdown & Estimation

## Mục đích
Hỗ trợ Sprint Planning. Bóc tách Epic/Feature thành các Technical Sub-tasks cụ thể cho team 8 người.

## Hướng dẫn cốt lõi
1. **Phân rã chi tiết**: Chia nhỏ công việc thành các mảng Backend (Python/Node.js), Frontend (JS/HTML), DevSecOps (Docker/K8s).
2. **Quản lý Dependencies**: Chỉ rõ Task nào block Task nào, xác định Critical Path.
3. **Giới hạn Effort**: Không có task nào được estimate vượt quá 2 man-days để tối ưu review code và giảm rủi ro.

## Trigger
Kích hoạt khi người dùng yêu cầu lập kế hoạch sprint, break down task, hoặc phân bổ nguồn lực.
